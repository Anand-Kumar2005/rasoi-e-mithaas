# 👨‍🍳 Rasoi-e-Mithaas

Rasoi-e-Mithaas is a simple and attractive Indian sweets recipe website built using HTML and CSS.

The website showcases popular Indian desserts along with their ingredients and step-by-step recipes. It is designed with a clean layout, responsive structure, and an interactive image overlay for each dish.

## 🍬 Featured Dishes

- Gulab Jamun
- Barfi
- Jalebi
- Rasmalai

## ✨ Features

- Clean and simple user interface
- Indian sweets recipe collection
- Ingredients section for each dish
- Step-by-step recipe instructions
- Attractive food images
- Navigation bar with Home, Menu, About and Contact sections
- Hover overlay effect on food images
- Responsive webpage structure
- Footer with copyright information

## 🛠️ Technologies Used

- HTML5
- CSS3
